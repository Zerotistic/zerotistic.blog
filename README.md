# zerotistic.blog

Personal blog on reverse engineering, pwn, automation and dumb ideas. Built with [Astro](https://astro.build) on the [astro-erudite](https://github.com/jktrn/astro-erudite) base, with a custom design.

```sh
pnpm install
pnpm dev      # local dev server
pnpm build    # static build to dist/
```
